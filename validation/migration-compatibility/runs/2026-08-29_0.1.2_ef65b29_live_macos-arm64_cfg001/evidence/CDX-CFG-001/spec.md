- Current official source:
  `https://developers.openai.com/codex/config-file/config-reference` (redirects to the
  ChatGPT Learn configuration reference; retrieved 2026-08-29).
- The reference states that user-level configuration lives in
  `~/.codex/config.toml` and documents `mcp_servers.<id>` with `command`, `args`, `env`,
  startup/tool timeouts, `required`, and default approval configuration.
- It also documents the three excluded candidate keys; their failure to win against
  Host/turn values is therefore a precedence observation, not invalid syntax.
